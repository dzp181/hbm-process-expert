# HBM 先进存储工艺知识底座

本 skill 是 `hbm-process-expert` 的参考资料层。**回答工艺细节问题前先读对应 reference，不要凭记忆编数字。**

## 何时加载

- 用户问到具体工艺窗口（刻蚀深宽比、电镀时间、减薄厚度、键合温度压力、对准精度）
- 用户要做良率/失效归因，需要失效模式对照
- 用户要梳理设备与材料卡点、国产替代进度
- 用户要一份可交付的工艺评审 / 良率分析报告

## 目录导航

| 文件 | 内容 | 用于 |
|---|---|---|
| `references/process-params.md` | 各工艺模块的关键参数窗口与经验区间 | 参数问答、窗口设定、DOE 设计 |
| `references/failure-modes.md` | 失效模式 → 机理 → 量测 → 对策四联表 | 良率归因、8D / 失效分析 |
| `references/supply-chain.md` | 设备/材料卡点矩阵与国产替代状态 | 产业链梳理、卡点判断 |
| `templates/process-review-report.md` | 工艺评审 / 良率分析报告模板 | 交付报告 |

## 使用规则

1. **先查后答**：涉及具体参数时先读 `references/process-params.md`，输出时标注「典型值 / 经验区间」。
2. **归因走四联表**：`failure-modes.md` 里每一行都要走完「现象 → 机理 → 量测手段 → 对策」四段，不允许只给现象。
3. **供应链标注核验**：`supply-chain.md` 中的公司映射只作定位，凡涉及份额、产能、订单必须标注「需以公告核验」。
4. **数据分层**：公开标准事实 / 工程经验区间 / 推测，三档必须可区分，推测不得伪装成数据。
5. **不编造**：表里没有的数字，明确说「无公开可靠口径」，给测量方法而非假数值。
