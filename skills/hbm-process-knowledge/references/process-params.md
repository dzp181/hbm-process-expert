# HBM 关键工艺参数窗口（经验区间）

> 口径说明：以下为公开文献与工程经验区间，非任何厂商机密参数。实际窗口需按产品、设备型号与节点标定。

## 1. TSV（via-middle）

| 项目 | 典型范围 | 控制要点 |
|---|---|---|
| 孔径 | 5–10 µm | 与 KOZ 应力预算耦合，孔径越大 KOZ 越宽 |
| 深度 / 深宽比（AR） | AR ≈ 8:1 – 12:1 | AR > 12 时填充难度陡增，void 风险显著上升 |
| 刻蚀方式 | DRIE（Bosch 循环） | 扇贝纹（scallop）深度直接决定侧壁绝缘连续性 |
| 侧壁角 | 89–90° | 角度偏差导致底部 CD 收窄、填充提前夹断 |
| 绝缘层 | TEOS / 亚常压 CVD，厚度与 AR 匹配 | 台阶覆盖不足 → 漏电、TDDB 退化 |
| 阻挡/种子层 | Ta/TaN + PVD Cu seed | 底部种子层不连续 → 填充从底部失效 |
| Cu 电镀 | 添加剂（加速剂/抑制剂/整平剂）配比驱动 bottom-up | 目标：无 void、无 seam、无突出 |
| CMP 露铜 | dishing 控制在 nm 级 | 露铜不足 → 接触电阻高；过磨 → 凹陷致键合不良 |
| Cu pumping | 退火后突出量 nm–数十 nm 级 | 直接影响堆叠共面度与混合键合良率 |

## 2. 晶圆薄化（TBDB）

| 项目 | 典型范围 | 控制要点 |
|---|---|---|
| 减薄后厚度 | 30–50 µm（部分路线 < 30 µm） | 越薄 TSV 深宽比越友好，但破片/翘曲风险陡增 |
| TTV | 亚微米级 | 影响堆叠高度一致性与键合压力均匀性 |
| 翘曲 | 随厚度、膜层应力非线性恶化 | 需与临时键合胶 Tg、支撑载板刚度联合设计 |
| 解键合 | 激光 / 热滑移 / 机械 | 残胶是后续键合空洞的常见根因 |

## 3. 键合

| 项目 | µbump + TC-NCF / MR-MUF | Hybrid Bonding |
|---|---|---|
| pitch | 约 25–40 µm（继续缩小受限） | 可到 10 µm 以下甚至个位数 |
| 对准精度 | 数 µm 级 | 亚 200 nm 级（先进设备向 <100 nm 走） |
| 表面要求 | 常规洁净度 | 粗糙度 < 1 nm 级、Cu 凹陷量精控、颗粒零容忍 |
| 热预算 | 较高（焊料回流 / 热压） | 较低（退火温度窗口窄但对齐要求极高） |
| 互连电阻/寄生 | 有 IMC、寄生较大 | Cu-Cu 直接键合，电阻与热阻更优 |
| 主要失效 | 冷焊、桥连、NCF 空洞、IMC 过厚 | 界面空洞、die shift、键合强度不足 |
| 返修性 | 相对可行 | 基本不可返修，前置良率要求极高 |

## 4. 塑封与组装

| 项目 | 关注点 |
|---|---|
| EMC 填料粒径 | 与 µbump pitch、间隙填充能力耦合；粒径过大 → 填充不足/压伤 |
| 模流与翘曲 | 堆叠总高度受封装规范约束（含基板、塑封、共面度） |
| 固化应力 | 与薄 die 叠加，是堆叠后翘曲与分层的主因之一 |
| KGSD | 堆叠前 KGD 筛选是控制乘性良率衰减的关键闸门 |

## 5. 良率数学关系

```
Y_stack ≈ Y_die^n × Y_bond^(n-1) × Y_assembly
```

- n = 堆叠层数。层数增加 50%（8→12），良率按指数衰减，这解释了「同工艺换 12-hi 就要重做工艺整合」。
- 混合键合把 `Y_bond` 的主导变量从「焊料润湿」换成「颗粒 + 表面状态 + 对准」，因此洁净室等级与 CMP 后表面成为一级 KPI。
